# Number-guessing-multiplayer-game-in-java
Java-based number guessing game with a two-player mode, attempt tracking, and winner logic.

🎯 Number Guessing Game (Java)

A simple console-based Java game where two players try to guess a randomly generated number between 1 and 100.

🚀 Features
Random number generation
Two-player mode
Tracks number of attempts
Declares winner based on least attempts
🛠️ How to Run
Compile the program:
javac Test.java
Run the program:
java Test
🎮 How to Play
Player 1 guesses the number first.
The program gives hints if the guess is too high or too low.
After Player 1 finishes, Player 2 plays.
The player with fewer attempts wins.
